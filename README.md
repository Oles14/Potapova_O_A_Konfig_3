# Практическая работа №3

Конфигурационное управление. Вариант 19. ИКБО-24-25.

## Описание

Ассемблер и интерпретатор учебной виртуальной машины на Python.

Ассемблер преобразует CSV-программы в машинный код. Интерпретатор выполняет машинные команды и сохраняет дамп памяти в формате XML.

## Этапы разработки

1. Перевод программы в промежуточное представление.
2. Формирование машинного кода.
3. Интерпретатор и операции с памятью.
4. Реализация арифметико-логического устройства.
5. Выполнение тестовой задачи.

## Команды УВМ

| Команда | Код | Размер | Назначение |
|---|---|---|---|
| LOAD,B,C | 4 | 5 байт | M[C] = B |
| READ,B,C,D | 9 | 5 байт | M[B] = M[M[D] + C] |
| WRITE,B,C | 0 | 4 байта | M[B] = M[C] |
| SHR,B,C,D | 3 | 5 байт | M[M[D]] = M[C] >> M[B] |

M — память виртуальной машины.

Исходная программа записывается в формате CSV без заголовков. Машинный код формируется в порядке little-endian.

## Память

Память команд и данных объединена и представлена списком из 4096 ячеек. Машинный код загружается с нулевого адреса. Данные представлены неотрицательными целыми числами.

## Структура проекта

- src/assembler.py — разбор CSV и формирование машинного кода.
- src/commands.py — спецификация, кодирование и декодирование команд.
- src/interpreter.py — память, выполнение команд, АЛУ и XML-дамп.
- tests/ — тестовые программы и автоматические тесты.
- run.bat — запуск ассемблера.
- run_interpreter.bat — запуск интерпретатора.

## Основные функции

- parse_command — разбор одной команды.
- parse_program — чтение CSV-программы.
- assemble_program — формирование машинного кода.
- print_program — вывод машинных байтов.
- get_spec — получение спецификации команды.
- encode_command — кодирование команды.
- decode_command — декодирование команды.
- check_address — проверка адреса памяти.
- execute_command — выполнение команды.
- run_program — выполнение машинной программы.
- save_dump — сохранение XML-дампа.

## Параметры ассемблера

- --input — исходный CSV-файл.
- --output — выходной двоичный файл.
- --test — вывод машинного кода.

## Параметры интерпретатора

- --input — двоичный файл программы.
- --output — XML-файл дампа памяти.
- --start — начальный адрес дампа.
- --end — конечный адрес дампа включительно.

## Запуск

Требуется Python 3.9 или новее. Дополнительные библиотеки не нужны.

Ассемблер:

`python -m src.assembler --input tests/vector1.csv --output vector1.bin --test`

Интерпретатор:

`python -m src.interpreter --input vector1.bin --output vector1.xml --start 500 --end 508`

В Windows также можно использовать run.bat и run_interpreter.bat.

## Итоговая задача

Поэлементный логический сдвиг вправо над двумя векторами длины 9 с сохранением результата в новый вектор.

Первый вектор расположен по адресам 300–308, второй — 400–408, результат — 500–508, указатели — 600–608.

Примеры программ:

- tests/vector1.csv — степени двойки.
- tests/vector2.csv — нечётные числа.
- tests/vector3.csv — граничные случаи.

Ожидаемые результаты:

1. [4, 4, 4, 4, 4, 4, 4, 4, 4]
2. [7, 15, 15, 31, 31, 63, 63, 127, 127]
3. [0, 1, 1, 0, 100, 0, 1, 0, 0]

Каждая программа после ассемблирования занимает 180 байт.

## Тестирование

`python -m unittest discover -s tests -v`

Всего предусмотрено 32 автоматических теста.

Проверяются разбор команд, машинный код, декодирование, операции с памятью, копирование массива, логический сдвиг вправо, обработка векторов и XML-дампы.
