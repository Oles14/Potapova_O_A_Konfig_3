# Практическая работа №3

Конфигурационное управление. Вариант 19.

## Описание

Ассемблер и интерпретатор учебной виртуальной машины на Python.

## Реализованные этапы

1. Перевод CSV-программы в промежуточное представление.
2. Формирование машинного кода.
3. Интерпретатор и операции с памятью.
4. Реализация арифметико-логического устройства.

## Команды ассемблера

| Команда | Код | Размер | Назначение |
|---|---|---|---|
| LOAD,B,C | 4 | 5 байт | M[C] = B |
| READ,B,C,D | 9 | 5 байт | M[B] = M[M[D] + C] |
| WRITE,B,C | 0 | 4 байта | M[B] = M[C] |
| SHR,B,C,D | 3 | 5 байт | M[M[D]] = M[C] >> M[B] |

M — память виртуальной машины.

Все четыре команды поддерживаются ассемблером и интерпретатором.

Исходная программа записывается в формате CSV без заголовков. Машинный код формируется в порядке little-endian.

## Память

Память команд и данных объединена и представлена списком из 4096 ячеек. Машинный код загружается с нулевого адреса. Данные представлены неотрицательными целыми числами. Дамп памяти сохраняется в формате XML.

## АЛУ

Реализован побитовый логический сдвиг вправо.

Первый операнд считывается по адресу C, количество позиций сдвига — по адресу B. Результат сохраняется по адресу, записанному в ячейке D.

Для вычисления используется оператор Python >>, который для неотрицательных чисел соответствует логическому сдвигу вправо.

## Функции

Ассемблер:

- parse_command — разбор команды.
- parse_program — чтение CSV-программы.
- assemble_program — формирование машинного кода.
- print_program — вывод машинных байтов.
- main — запуск ассемблера.

Обработка команд:

- get_spec — получение спецификации команды.
- encode_command — кодирование команды.
- decode_command — декодирование команды.

Интерпретатор:

- check_address — проверка адреса памяти.
- execute_command — выполнение команд, включая SHR.
- run_program — выполнение машинной программы.
- save_dump — сохранение XML-дампа.
- main — запуск интерпретатора.

## Параметры ассемблера

- --input — исходный CSV-файл.
- --output — выходной двоичный файл.
- --test — вывод машинного кода.

## Параметры интерпретатора

- --input — двоичный файл программы.
- --output — XML-файл дампа памяти.
- --start — начальный адрес дампа.
- --end — конечный адрес дампа включительно.

## Запуск

Требуется Python 3.9 или новее. Дополнительные библиотеки не нужны.

Ассемблирование программы:

`python -m src.assembler --input tests/shift.csv --output shift.bin --test`

Выполнение программы:

`python -m src.interpreter --input shift.bin --output shift.xml --start 200 --end 205`

В Windows также используются скрипты run.bat и run_interpreter.bat.

## Тестирование

`python -m unittest discover -s tests -v`

Всего предусмотрено 29 автоматических тестов.

Проверяются разбор команд, машинный код, декодирование, операции с памятью, копирование массива, XML-дамп и логический сдвиг вправо.
